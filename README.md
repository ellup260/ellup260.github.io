# Elson Pereira — Portfolio website

A responsive, single-page portfolio designed for GitHub Pages using HTML, CSS and vanilla JavaScript. No build step or framework installation is required.

## Publish on GitHub Pages

1. Open https://github.com/ellup260/ellup260.github.io
2. Add or upload `index.html` to the repository root.
3. Commit the file to the `main` branch.
4. Open **Settings → Pages**.
5. Set **Source** to **Deploy from a branch**, choose **main** and **/(root)**, then Save.
6. Wait for deployment, then visit https://ellup260.github.io/
